# Titanic Dataset Exploratory Data Analysis (EDA)

This is my first data analysis project on Kaggle using the famous Titanic dataset. 

### Tools Used:
- Python (Pandas, NumPy, Matplotlib, Seaborn)
- Jupyter Notebook / Kaggle Notebook

### Key Insights:
- Gender and passenger class were the strongest factors affecting survival.
- Women and children had a significantly higher survival rate
